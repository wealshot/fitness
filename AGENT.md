## 2. Протокол Мышления и Поведения

### Caveman Mode
- **Меньше слов, больше дела.** Без длинных вступлений, извинений и пустых рассуждений.
- Получил задачу → проанализировал → выдал рабочий код.
- Отвечать коротко и по делу. Экономить токены.
- Не объяснять очевидное. Не повторять задачу обратно пользователю.

### Ruflo Framework
- **Системное мышление.** Не писать код вслепую.
- Сначала планировать структуру и продумывать последствия изменений для всего проекта.
- Координировать автономные процессы, учитывать зависимости между модулями.
- Использовать адаптивную память в рамках сессии.

### Context Mode
- **Фокус на контексте.** Работать только с файлами текущей задачи.
- Не перегружать контекстное окно лишними данными.
- Сокращать вывод инструментов, оптимизировать расход памяти.

## 3. Архитектура Конвейера (Multi-Tenant & Config-Driven)
Строго соблюдать архитектуру **Zero-Hardcode**:
- **Единый центр данных:** Весь клиентский контент (имя, ниша, аватар, акцентный цвет, офферы, услуги, цены, вопросы квиза, отзывы, Telegram) хранится в `clients.js` (`window.CLIENTS`).
- **Мульти-клиентский роутинг:** Динамический рендеринг по пути (`/:clientSlug`) или параметру (`?client=slug`) с фоллбэком на дефолтный профиль (`gleb`).
- **Динамическая темизация:** Акцентный цвет прокидывается в CSS-переменные (`--accent-color`, `--accent-glow`, `--accent-dim`).

## 4. Деплой и Vercel Production Ready
- **SPA Routing:** В корне обязателен `vercel.json` с rewrites (`/(.*) -> /index.html`) для исключения 404 на Vercel.
- **Zero-Break Builds:** Чистые импорты, отсутствие неиспользуемых переменных, корректные пути к ассетам.
- **TMA & Mobile Web Hybrid:** Верстка под безопасные зоны мобильных браузеров и Telegram WebView (`100dvh`, `safe-area-inset-bottom`), строгий `overflow-x: hidden`.

## 5. Визуал, Эстетика и Конверсия (UI/UX & CRO)

### UI/UX Pro Max & Taste Standard
- Mobile-first: эталонный контейнер 430px по центру на десктопе с фоновым окружением, 100% ширины на мобильных.
- Премиальный коммерческий визуал: глубокие темные фоны (`#09090B`, `#0F0F12`), деликатные бордеры (`border-white/10`), glassmorphism (`backdrop-blur-xl`), плотная типографика.
- Плавные micro-animations (CSS transitions / Framer Motion).

### Conversion Engine (CRO & Hormozi)
- **Триггеры доверия:** Живые статусы («Свободно 2 места», пульсирующий онлайн-индикатор), твердые цифры кейсов.
- **Интерактив:** Микро-калькуляторы КБЖУ, квизы подбора программы, интерактивные слайдеры «до/после».
- **Бесшовный лидген:** Sticky-кнопка CTA автоматически собирает выбранные параметры и генерирует готовую Deep-Link ссылку в Telegram (`https://t.me/username?text=...`).
